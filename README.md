# Aulas-Dev-Python

## 15 problemas de programação — nível moderado a difícil

Este notebook avalia exclusivamente os conceitos estudados na **Aula 1**.

### Conceitos permitidos

- lógica de programação;
- decomposição de problemas;
- algoritmos;
- variáveis e atribuição;
- `int`, `float`, `str`, `bool` e `None`;
- conversões básicas de tipos;
- operadores aritméticos;
- operadores relacionais;
- operadores lógicos;
- entrada e saída;
- `if`, `elif`, `else`;
- `for`;
- `while`;
- `range`;
- funções;
- parâmetros;
- argumentos;
- valores de retorno;
- escopo básico.

## Regras de implementação

As soluções devem ser construídas **somente com os conceitos acima**.

Não utilize:

- listas, tuplas, dicionários ou conjuntos;
- `import` ou bibliotecas;
- métodos de `str`;
- `break` ou `continue`;
- `try`/`except`;
- orientação a objetos;
- recursão;
- compreensões;
- `match`;
- funções prontas como `min`, `max`, `sum`, `sorted`, `reversed` ou `abs` para resolver a lógica principal;
- conversão para `str` quando o problema proibir explicitamente essa conversão.

Uma solução que funcione, mas utilize recursos fora do escopo, **não atende ao enunciado**.

## Como responder

Em cada problema há três partes obrigatórias:

1. **Previsão e decomposição:** escreva, em comentários, de 2 a 5 linhas explicando entradas, processamento e saída.
2. **Implementação:** escreva seu programa.
3. **Microdefesa:** responda, em comentários, à pergunta conceitual indicada.

Os casos de teste indicados fazem parte do enunciado. Seu programa deve funcionar para todos eles.

> Durante a correção, qualquer solução poderá ser acompanhada de uma explicação oral curta sobre uma linha, condição ou variável escolhida pelo professor.
